## 📌 Projetos em destaque

🔹 **Projeto de Plataforma de Dados (Data Mesh) para grande banco financeiro**  
Projeto de plataforma de dados (Data Mesh) voltado à democratização de dados e escalabilidade operacional. A iniciativa entregou um orquestrador central para ~180 AWS Glue Jobs em pipeline diário, consolidando e distribuindo dados unificados para diferentes squads.  
Também foi implementada uma estratégia de resiliência com MTTR de poucos minutos em falhas de fontes, além de observabilidade ponta a ponta com Datadog (monitoramento, rastreabilidade e troubleshooting proativo).  
A arquitetura foi desenhada em modelo cross-account, habilitando o atendimento de 5 comunidades, com integração de fontes legadas sob princípios de governança, padronização e evolução contínua da plataforma.
